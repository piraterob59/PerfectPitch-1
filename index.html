          Settings

          The pitch accuracy target is set per song: tap the "±N¢" next to the song title on the practice screen to change it. Each recorded attempt keeps the target it was scored with.

          Backup

          Your song library, stems, pitch data, and recorded attempts live only in this browser, on this device — there's no cloud copy. Export a backup before clearing site data or switching devices, or just every so often, so you're never one "clear storage" away from starting over.

          About

          PitchPerfect separates vocals from instrumentals using LALAL.AI. Since LALAL.AI's API blocks direct calls from a browser, imports go through a small proxy (see worker/README.md in the project repo) that holds the LALAL.AI license key server-side — nothing secret is stored on this device or in this app's code.

          Everything else — your song library, separated stems, and pitch data — is stored only on this device, in this browser's local database.
